# EmployeeMailbox

A sample app for mailbox management.

The Application it self rests on `EmployeeMailbox` folder. On `Specification` folder you will find the Cucumber Specifications for EmployeeMailbox.

## Requirements 

The application should generate a mailbox for a given employee that match.

1. Email Address should be on shape firstname.lastename@department.company.com
2. Default mailbox size is 50 mb, but bosses have 100 mb.
3. Employee needs enter a alternative e-mail address
4. Every Employee have a unique CPF document
